# cards blocks

Self-contained Cards preview blocks. Each file owns its sample data and imports
only Sand components.

- [revenue-card.tsx](revenue-card.tsx) - revenue stat and spark area chart
- [subscription-card.tsx](subscription-card.tsx) - subscription upgrade form
- [chat-card.tsx](chat-card.tsx) - short support conversation
- [invoices-card.tsx](invoices-card.tsx) - recent invoice table
- [activity-card.tsx](activity-card.tsx) - weekly activity bar chart
- [date-card.tsx](date-card.tsx) - selected date calendar
