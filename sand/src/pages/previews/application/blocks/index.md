# application blocks

Self-contained Application preview blocks. Each file owns its sample data and
imports only Sand components.

- [ticker.tsx](ticker.tsx) - four live instrument tiles
- [market-chart.tsx](market-chart.tsx) - price chart with range tabs
- [transactions.tsx](transactions.tsx) - ledger rows filtered by status
- [activity-feed.tsx](activity-feed.tsx) - workspace activity with kind tabs
- [messaging.tsx](messaging.tsx) - short team conversation
