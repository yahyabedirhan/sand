# mechanics

Write each mechanic page with [mechanic-page.tsx](mechanic-page.tsx) and register it in [docs/registry.ts](../../docs/registry.ts). Follow `.scratch/sand-build/page-format.md`. Primitives is the reference. No setup guides.

- [mechanic-page.tsx](mechanic-page.tsx) - header, owns, preview or code-only pane, parts chip row, links, alternatives
- [primitives.tsx](primitives.tsx) - Base UI
- [icons.tsx](icons.tsx) - Tabler
- [charts.tsx](charts.tsx) - Recharts
- [fonts.tsx](fonts.tsx) - fontsource wiring and token mapping, code only
- [animation.tsx](animation.tsx) - named tw-animate-css demos with replay
- [react.tsx](react.tsx) - React through representative component code
- [vite.tsx](vite.tsx) - Vite config, plugins, and alias, code only
- [tailwind.tsx](tailwind.tsx) - Tailwind
- [shadcn.tsx](shadcn.tsx) - the shadcn registry, config path on the code pane
