# Sand

This folder is the Sand snapshot this project owns. Import components from
`sand/ui/...` and the stylesheet from `sand/styles.css`. Point `@/` at this
package's `src/` in Vite and TypeScript; keep the app's own imports relative.

## Install

Follow [installation.md](installation.md) to adopt or update Sand. It covers
a new project, an existing project (list changes, confirm, then act), and
the overwrite script.

## Rules

Read [rules/index.md](rules/index.md) before using or changing a Sand topic.

## Guides

Read [guides/index.md](guides/index.md) when moving to a release that ships
breaking changes. Otherwise run the update script in the installation guide.
