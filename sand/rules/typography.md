# Typography rules

## Use a role, not a size

One utility carries size, line height, weight, and tracking; the raw scale is for exceptions.

## Keep one heading-1 per page

The page title is heading-1; sections step down to heading-2.

## Do not shrink body text below body-sm for reading

Caption is for labels and hints, not for a paragraph.

## Use the code role for code, keys, and numbers that align

Mono with tabular figures keeps the columns straight.
