# 05: Application preview

**What to build:** The Application preview shows a small in-app screen: a chat widget, a transactions list, an activity feed, and similar building blocks arranged as one working surface, so a token change is visible across an application layout.

**Blocked by:** 04 Previews section and the Cards preview

**Status:** ready-for-agent

- [ ] reflows to a reasonable minimum width without breaking
- [ ] light and dark both correct
